# Changelog

All notable changes to AETHER are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.1.0] - 2026-09-04

### Added

- Hyperdimensional computing substrate: bipolar hypervectors with bundling,
  binding/unbinding, permutation, n-gram encoding and holographic memory.
- Resonant oscillatory neurons with Kuramoto mean-field coupling and
  amplitude relaxation.
- Entangled multi-scale attention: sliding-window local branch fused with a
  holographic gist branch through a learned per-position resonance gate.
- Sparse mixture of SwiGLU experts with noisy top-k routing and a
  Switch-style load-balancing auxiliary loss.
- Fractal memory hierarchy: sensory ring, attended working set, Ebbinghaus
  episodic store, consolidated semantic prototypes, full recall cycle.
- Online plasticity: Oja Hebbian bank, homeostatic gain control, STDP window.
- `AetherMind`: stateful forward pass, autoregressive generation
  (temperature / top-k / nucleus), flat-param evolution interface, JSON
  snapshots of the whole organism.
- Derivative-free training: AdamW, cosine schedule, antithetic evolutionary
  strategies with gradient clipping and entropy bonus.
- Creativity engine: divergent temperature forests, novelty archive,
  holographic conceptual blending, iterative dreaming with self-rated
  coherence.
- Trainable deterministic BPE tokenizer with save/load and Unicode support.
- `aether` CLI (`info`, `demo`, `train`, `dream`, `tokenize`).
- Criterion micro-benchmarks, integration tests, doc examples.
- Full CI matrix: fmt, clippy, multi-OS build/test, docs, MSRV, benches,
  coverage, and an end-to-end showcase job with transcript artifacts.
